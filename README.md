## 🎯 نبذة عن المشروع

تطبيق Streamlit احترافي لإدارة المعاينات الكهربائية مع تصميم عصري (Gamma Design System) و Chatbot ذكي مدعوم بـ Claude AI.

---

## ✨ المميزات الرئيسية

### 📊 لوحة التحكم (Dashboard)
- عرض الإحصائيات الرئيسية
- رسوم بيانية تفاعلية (3 charts)
- جداول بيانات ذكية

### 📝 إدارة البيانات
- 4 tabs للبيانات المختلفة:
  - بيانات المشروع
  - الأسعار والشروط المالية
  - معايير التقييم
  - الصيغ الحسابية

### 📚 إدارة المصادر
- رفع الملفات المتعددة
- حفظ دائم للملفات
- حذف الملفات

### 📈 التحليل والمقارنة
- جداول تفصيلية
- بيانات مقارنة شاملة
- توصيات ذكية

### 📄 التقارير
- تقارير شاملة
- تقارير موجزة
- تقارير مالية

### 💬 Chatbot الذكي
- نظام RAG متقدم
- تكامل مع Claude AI
- سجل محادثات
- واجهة جميلة في Sidebar

## 🚀 البدء السريع

### 1. التثبيت

```bash
# انتقل للمشروع
cd "/Users/fahadalkandri/Desktop/Projects/مهندس كهربائي مساعد"

# ثبت المتطلبات
pip install -r requirements.txt
```

### 2. إعداد الـ API (اختياري)

```bash
# عدّل ملف .env
nano .env

# أضف:
# ANTHROPIC_API_KEY=your_actual_api_key
# CLAUDE_MODEL=claude-3-5-sonnet-20241022
```

احصل على API Key من: https://console.anthropic.com/

### 3. التشغيل

```bash
streamlit run app.py --server.port 9876
```

**الرابط:** http://localhost:9876

## 🎯 الاستخدام

### Dashboard
1. اذهب لصفحة Dashboard
2. عرض الإحصائيات والرسوم البيانية
3. اطلع على الجداول والبيانات

### إدارة البيانات
1. اذهب لـ "إدخال البيانات"
2. اختر التاب المطلوب
3. أضف أو عدّل البيانات
4. اضغط "حفظ"

### رفع الملفات
1. اذهب لـ "المصادر"
2. اختر الملفات المراد رفعها
3. الملفات تُحفظ تلقائياً

### التقارير
1. اذهب لـ "التقارير"
2. اختر نوع التقرير
3. حدّد المكونات المراد تضمينها
4. أنشئ التقرير

### الـ Chatbot
1. في Sidebar، اكتب سؤالك
2. اضغط زر الإرسال
3. سيحصل على رد من Claude AI
