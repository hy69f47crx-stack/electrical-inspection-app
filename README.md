## 🎯 سير العمل الكامل

### المرحلة الأولى: جمع البيانات (Mobile)
```
1. الخبير يذهب للموقع
2. يفتح تطبيق الجوال
3. ينتقي المشروع والطابق
4. يملأ البيانات لكل بند:
   - الكمية المنفذة
   - جودة التنفيذ (جيد/معيب/ناقص)
   - يضيف صور توضيحية
   - يسجل موقع GPS
5. يحفظ البيانات محلياً
6. عند الاتصال، يتزامن البيانات تلقائياً
```

### المرحلة الثانية: التحليل (Web)
```
1. يفتح تطبيق الويب
2. يختار المشروع
3. يرى مقارنة بيانات (مخطط vs منفذ)
4. يحلل الرسوم البيانية
5. يكتب ملاحظات التقييم
```

### المرحلة الثالثة: الحسابات (Web)
```
1. يدخل البيانات المالية
2. النظام يحسب:
   - نسبة الإنجاز
   - المبلغ المستحق
   - الخصومات والإضافات
   - الرصيد النهائي
```

### المرحلة الرابعة: التقرير (Web)
```
1. يختار نوع التقرير
2. يحدد المحتويات
3. يعاين PDF
4. يطبع أو يرسل
```

## ❓ الأسئلة المتكررة (FAQ)

### س: هل التطبيق يعمل بدون انترنت؟
**ج:** نعم! يعمل الجوال بشكل كامل بدون انترنت، والتزامن يحدث لاحقاً عند الاتصال.

### س: كم مستخدم يمكن للتطبيق أن يدعم؟
**ج:** المرحلة الأولى معدة لـ 3-10 خبراء. يمكن توسيعها لاحقاً للـ 100+ مستخدم.

### س: هل يدعم التقارير الطباعة؟
**ج:** نعم بالكامل! يمكن طباعة PDF أو حفظه أو إرساله عبر البريد.

### س: ما الفرق بين الدفعات الدورية والختامية؟
**ج:** الدفعات الدورية تكون أثناء العمل (بناء على الإنجاز)، الختامية بعد انتهاء العقد.
